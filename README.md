# Invoice Chaser — Automated follow-ups for accounting firms

An n8n workflow that chases clients for missing documents and invoices so accountants don't have to. Built to be sold as a productized service to small accounting/bookkeeping firms.

## What it does

Every weekday at 9am (firm's timezone):

1. Reads the client tracker (Google Sheet) and finds rows that are still being chased **and** due for a follow-up.
2. Sends the right email for the client's stage:
   - Stage 0 → polite first reminder
   - Stage 1 → firmer reminder with a deadline
   - Stage 2 → final notice
   - Stage 3 → stops emailing, escalates to the accountant with a summary
3. Optionally personalizes one opening line with Gemini. If Gemini fails, times out, or returns garbage, the static template still goes out. **The send never depends on the AI.**
4. Updates the tracker (stage +1, status, last-sent date) and appends every send to an Email Log tab for audit.
5. Any failure anywhere → logged to the Email Log as `failed` + the firm owner gets an alert email. Nothing fails silently.

## Files

- `n8n-workflow.json` — import into n8n (Workflows → Import from file). Generated by `build_workflow.py`.
- `email-sequences.md` — the three email templates with placeholders.
- Tracker sheet template: create a Google Sheet with tabs `Tracker`, `Email Log`, `Templates` (columns documented below).

## Setup (about 30 minutes)

1. Import `n8n-workflow.json` into n8n.
2. Replace every `PASTE_...` placeholder:
   - `PASTE_TRACKER_SHEET_ID_HERE` → your Google Sheet ID (4 nodes)
   - `PASTE_GEMINI_API_KEY_HERE` → your Gemini API key from Google AI Studio (free tier)
   - `PASTE_OWNER_EMAIL_HERE` → the firm owner's email for error alerts
3. Add credentials on the nodes marked "ADD YOUR ...":
   - Google Sheets OAuth2 (Read Tracker, Update Tracker Row, Log Email, Mark Escalated, Log Failure)
   - Gmail OAuth2 (Send Follow-up, Escalate to Accountant, Alert Owner)
4. Set the workflow timezone to the firm's timezone (workflow settings).
5. Activate. Test with one fake client row first.

## Tracker sheet columns

`client_name | client_email | document_needed | amount | status | followup_stage | last_sent | next_followup | accountant_email | notes`

- `status`: `awaiting`, `f1_sent`, `f2_sent`, `final_sent`, `received`, `escalated`, `paused`
- `next_followup`: formula `=IF(G2="",TODAY()-1,G2+4)` — new rows are due immediately, then every 4 days
- The workflow only touches rows with an active status whose `next_followup` is today or past.

## How it handles failure (the part that sells it)

- One client row failing never blocks the others (batch loop).
- Gemini down → static template still sends.
- Gmail/Sheets error → error output alerts the owner + logs `failed` in the Email Log.
- Client replies → (v2) classify reply and pause the sequence; v1 pauses on any status change to `received`/`paused`.
